# University core diagnostic

This quiz covers the 45 lessons of the university core folder: two questions on each of the 42 core lessons and one on each of the 3 optional lessons (parametric, polar and 3D coordinates; double integrals; second-order linear equations), 87 questions in all. Take it without notes, and write every answer down before you look at the answers. A calculator is allowed, and you should use it where a question asks for a decimal. Most questions take one to three minutes, so plan on five or six sittings rather than one. Every question here is a small version of something its lesson teaches, and none asks for a full proof.

Mark each answer right, wrong or guessed. A guess counts as wrong, even when it turns out right. Then do only the lessons behind the questions you marked wrong or guessed; the answer table names the lesson for each one. Several questions ask for a reason, and an answer without its reason counts as wrong. If you skip the three optional lessons, nothing later depends on them. All data in the questions are made up (hypothetical).

## Limits and continuity

1\. Find $\lim_{x \to 1} \dfrac{x^2 + x - 2}{x^2 - 1}$.

2\. Find (a) $\lim_{x \to 0} \dfrac{\sin 3x}{x}$ and (b) $\lim_{x \to \infty} \dfrac{5x^3 - x}{2x^4 + 1}$.

3\. For $f(x) = 5x + 2$, $a = 1$ and $L = 7$, find the largest $\delta$ that guarantees $\lvert f(x) - 7 \rvert < 0.1$ whenever $0 < \lvert x - 1 \rvert < \delta$.

4\. True or false, with a reason: if a number $\delta$ works for $\varepsilon = 0.5$, then the same $\delta$ also works for $\varepsilon = 0.1$. Test your answer on $f(x) = 3x$ at $a = 0$ with $\delta = 0.1$.

5\. Let $f(x) = kx + 1$ for $x < 2$ and $f(x) = x^2$ for $x \ge 2$. Find the value of $k$ that makes $f$ continuous at 2.

6\. A function $f$ is continuous on $[1, 3]$ with $f(1) = 4$ and $f(3) = -2$. Must $f$ have a zero in $(1, 3)$? Must the equation $f(x) = 5$ have a solution in $(1, 3)$? Give the reason in each case.

## Derivatives

7\. Use the limit definition to find $f'(2)$ for $f(x) = \dfrac{1}{x}$.

8\. True or false, with a reason: if $f$ is continuous at $a$, then $f$ is differentiable at $a$. If it is false, give an example.

9\. Differentiate $f(x) = \dfrac{x^2 + 1}{e^x}$ and simplify.

10\. A student writes $\dfrac{d}{dx}(x \sin x) = \cos x$. Name the mistake, give the correct derivative and find its value at $x = \pi$.

11\. Differentiate $f(x) = \ln\left(\sin\left(x^2\right)\right)$.

12\. (a) Find the slope of the curve $x^3 + y^3 = 6xy$ at the point $(3, 3)$. (b) Let $g$ be the inverse of $f(x) = x^3 + x$. Find $g'(2)$.

## Probability
