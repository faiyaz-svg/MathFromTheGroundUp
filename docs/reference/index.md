# Reference

These pages are for looking things up: in the middle of a lesson, while reading a proof in a course, or when a symbol or word on a problem set stops you. Each entry links back to the lesson that teaches it. Lessons that are not written yet appear as plain names and become links as they are written.

| Page | What it holds |
|---|---|
| [Symbols and notation](symbols-and-notation.md) | Every symbol in the book with its LaTeX, how to say it, its meaning and an example; the Greek alphabet; the letter this book uses for each kind of object |
| [Glossary](glossary.md) | Plain definitions of the terms used across the book, with extra attention to the language of proofs |
| [Common mistakes](common-mistakes.md) | Classic errors grouped by topic, each with the wrong version, the right version and the reason |
| [Formula index](formula-index.md) | Where each chapter's cheat sheet is, and the most-used formulas with the lessons they come from |

If a proof stops making sense, check its symbols on the symbols page first. Then find each word you can't define in a sentence of your own, and look it up in the glossary. In proof-heavy courses, a lot of the trouble comes from notation you can't read yet and definitions you only half know.
